package vortex // import "github.com/fclairamb/vortex-go"

Package vortex reads and writes files in the Vortex columnar format.

Open and OpenFile read the trailer, the footer and the schema of a file. Reading
rows and writing files are not implemented yet. The goals are in docs/goals.md,
the planned interface in docs/interface.md and the test plan in docs/testing.md.

VARIABLES

var (
	// ErrNotVortex means the file does not start and end with the Vortex magic, or is too short.
	ErrNotVortex = errors.New("vortex: not a Vortex file")
	// ErrUnsupportedVersion means the file has a format version this package does not read.
	ErrUnsupportedVersion = errors.New("vortex: unsupported format version")
	// ErrCorrupt means a part of the file is out of bounds or malformed.
	ErrCorrupt = errors.New("vortex: corrupt file")
)
    The errors Open returns, to test with errors.Is. Their messages carry the
    byte offset.


TYPES

type Field struct {
	Name string
	Type Type
}
    Field is a named field of a struct.

type File struct {
	// Has unexported fields.
}
    File is an open Vortex file. It is safe for concurrent use.

func Open(r io.ReaderAt, size int64) (*File, error)
    Open reads the trailer, the footer and the schema of the Vortex file in r,
    which holds size bytes. It reads the last 64 KiB in one call, and one more
    range when the footer reaches further back. A file larger than 64 KiB costs
    one more read, for its first bytes. The caller keeps r open for as long as
    the File is used.

func OpenFile(path string) (*File, error)
    OpenFile opens the Vortex file at path. Close it when done.

func (f *File) Close() error
    Close closes the file that OpenFile opened. It does nothing for a File made
    by Open. A second call returns nil.

func (f *File) NumRows() int64
    NumRows returns the number of rows of the file.

func (f *File) Schema() *Schema
    Schema returns the schema of the file.

type Kind uint8
    Kind is the logical type of a column.

const (

    The logical types of a Vortex file. Union exists upstream but is in no

func (k Kind) String() string
    String returns the name of the kind, like "i32" or "fixed_size_list".

type Schema struct {
	// Has unexported fields.
}
    Schema is the schema of a file: the fields of its root struct.

func (s *Schema) Field(name string) (Field, bool)
    Field returns the first field with this name.

func (s *Schema) Fields() []Field
    Fields returns a copy of the fields, in file order.

func (s *Schema) String() string
    String returns the root struct, like Type.String.

type Type struct {
	// Has unexported fields.
}
    Type is a logical type. It is a value: compare two of them with Equal,
    not with ==. An accessor that does not apply to the kind of the type returns
    the zero value.

func (t Type) Elem() Type
    Elem is the element type of a list or a fixed-size list.

func (t Type) Equal(o Type) bool
    Equal reports whether the two types are the same, nullability included.

func (t Type) Fields() []Field
    Fields returns a copy of the fields of a struct.

func (t Type) Key() Type
    Key is the key type of a map.

func (t Type) Kind() Kind
    Kind returns the logical type.

func (t Type) Nullable() bool
    Nullable reports whether the values may be null. It is always true for Null.

func (t Type) Precision() int
    Precision is the number of digits of a decimal.

func (t Type) Scale() int
    Scale is the number of digits of a decimal after the point. It can be
    negative.

func (t Type) Size() int
    Size is the number of elements of every value of a fixed-size list.

func (t Type) String() string
    String returns the type in a short form: "i32", "utf8?" (nullable),
    "decimal(10,2)", "list<i32>", "map<utf8, i64>", "timestamp[ms, tz=UTC]",
    "struct{a: i32, b: utf8?}".

func (t Type) Unit() Unit
    Unit is the time unit of a date, a time or a timestamp.

func (t Type) Value() Type
    Value is the value type of a map.

func (t Type) Zone() string
    Zone is the time zone of a timestamp, empty when it has none.

type Unit uint8
    Unit is the time unit of a date, a time or a timestamp.

const (
	Nanosecond Unit = iota
	Microsecond
	Millisecond
	Second
	Day
)
    The time units, with the values of the file format.

func (u Unit) String() string
    String returns "ns", "us", "ms", "s" or "days".
