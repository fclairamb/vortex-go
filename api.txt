package vortex // import "github.com/fclairamb/vortex-go"

Package vortex reads and writes files in the Vortex columnar format.

Open and OpenFile read the trailer, the footer and the schema of a file.
Scan reads columns of numbers, booleans, strings, binaries, decimals, lists,
maps and structs, batch by batch, for the columns, the row range and the filter
of a Query, and skips what the statistics of the file rule out. Rows reads the
same rows into Go structs. NewWriter writes a file from a Schema and Data,
in chunks of 8,192 rows, with zone statistics and dictionaries, and the
encodings of each chunk picked by a compressor, like the reference writer,
and NewRowWriter writes a slice of structs. The goals are in docs/goals.md,
the planned interface in docs/interface.md and the test plan in docs/testing.md.

FUNCTIONS

func Rows[T any](ctx context.Context, f *File, q Query) iter.Seq2[T, error]
    Rows reads the rows of the file that meet the query into values of T,
    a struct, batch by batch, and yields them one by one. The columns it reads
    come from the fields of T, so the query only selects rows: the scan is the
    one of File.Scan.

    A field takes the column named by its tag, vortex:"name", else its own name.
    The tag vortex:"-" skips the field, vortex:"name,optional" leaves the field
    at its zero value when the file has no such column. Unexported fields are
    skipped and embedded structs are flattened. The Go type of a field must be
    the one the column type calls for, with no widening:

      - bool, the numbers (int and uint are 64 bits), and float32 for a f16
        column;
      - vortex.Decimal for a decimal, or int64 when its precision is 18 or less;
      - string (a copy, see below) or []byte (a view, valid in the loop body)
        for utf8, []byte for binary;
      - time.Time for a date and a timestamp (UTC unless the type has a zone),
        time.Duration since midnight for a time, or their storage integer;
      - [16]byte for a uuid;
      - a struct for a struct, []X for a list, [N]X or []X for a fixed-size
        list, map[K]V for a map, and any for a variant (see Column.Variant).

    A nullable column needs sql.Null[X] or *X; a column that is not nullable
    takes those and the plain type. A column of type null has no Go type:
    leave its field out.

    A field whose type is a number, a bool, a decimal, a time, a uuid, a string
    or a []byte, plain or in sql.Null, is filled without allocating for the row.
    Pointers, slices, maps and variants allocate for each row.

    The strings of such a field share one block per batch, a copy of their bytes
    that the garbage collector owns, never the memory of the scan or of a mapped
    file: they stay valid after the loop. The block is at most the bytes of the
    strings of that field in the batch (8192 rows at most), and one string kept
    keeps its whole block alive: use strings.Clone to keep a few strings of many
    batches.

    A field that does not fit its column, a missing column, a T that is not a
    struct, and every error of Scan, come back as the error of the iteration,
    and the loop ends. A field problem is found before any data is read.

func Values[T Number](c *Column) ([]T, error)
    Values returns the values of a numeric column as a slice of T, null rows
    included (their value is unspecified: check Null). It returns an error,
    naming both types, when the column is not a T. A f16 column is read as
    float32. The slice is a view, valid for the iteration.


TYPES

type Batch struct {
	// Has unexported fields.
}
    Batch is a group of rows of the columns of a scan. It and its columns are
    valid for one iteration of the loop.

func (b *Batch) Col(i int) *Column
    Col returns the column i of the batch, in the order the columns were asked
    for. It panics when i is out of range.

func (b *Batch) Len() int
    Len is the number of rows of the batch.

type Column struct {
	// Has unexported fields.
}
    Column is a view of the values of one column in a batch.

func (c *Column) Bool(i int) bool
    Bool returns the value of row i of a Bool column. It panics when the column
    is of another type, and when i is out of range.

func (c *Column) Bytes(i int) []byte
    Bytes returns the bytes of row i of a Utf8, Binary or UUID column: a view,
    valid until the next batch. It panics when the column is of another type,
    and when i is out of range.

func (c *Column) Decimal(i int) Decimal
    Decimal returns the unscaled value of row i of a Decimal column, whatever
    its precision and the width it is stored at. It panics when the column is of
    another type, and when i is out of range.

func (c *Column) Elems() *Column
    Elems returns the elements of a List, FixedSizeList or Map column,
    all the rows' together. For a map, they are structs of two fields, the key
    and the value. List gives the range of a row. It panics when the column is
    of another type.

func (c *Column) Field(i int) *Column
    Field returns the field i of a Struct column. It panics when the column is
    of another type, and when i is out of range.

func (c *Column) List(i int) (start, end int)
    List returns the range of Elems that holds row i of a List, FixedSizeList
    or Map column: the elements from start to end, end excluded. Ranges of
    different rows may overlap. It panics when the column is of another type,
    and when i is out of range.

func (c *Column) Null(i int) bool
    Null reports whether row i is null. It panics when i is out of range.

func (c *Column) Type() Type
    Type is the logical type of the column.

func (c *Column) Variant(i int) (any, error)
    Variant decodes row i of a Variant column, a null row being nil.
    The value is nil, a bool, an int64, a float64, a string, a []byte,
    a time.Time (a date, a time of day on 1970-01-01, or a timestamp, in UTC),
    a VariantDecimal, a []any or a map[string]any. Every call allocates:
    the result is a copy, valid after the batch. An error means the value of the
    file is damaged. It panics when the column is not a Variant, and when i is
    out of range.

type Compression uint8
    Compression is how much effort the writer spends to make the file smaller.

const (
	// Default is the level to use when there is no reason to pick another: the compressor
	// picks the lightweight encodings of each chunk (bit-packing, frame of reference,
	// dictionaries, run-end, ALP, FSST...), as the reference writer does.
	Default Compression = iota
	// Compact favors a small file over the time to write it: zstd is a candidate too, for
	// the numbers and the strings.
	Compact
	// None writes the values as they are, in plain arrays.
	None
)
    The compression levels.

type Data struct {
	// Has unexported fields.
}
    Data is the values of one column, in the shape Go holds them. Build one with
    Of, OfBools, OfStrings, OfBytes, OfDecimals, OfNulls, OfStruct or OfList.
    Which Data a column takes is set by its type, see Writer. A Data refers to
    the slices it was made from: the writer reads them during Write and keeps no
    reference afterwards.

func Of[T Number](v []T) Data
    Of is the values of a column of numbers: Int8 to Float64, the storage of
    a date, a time or a timestamp (int32 for a date in days and for a time
    in seconds or milliseconds, else int64), and the 16 bits of a Float16 as
    uint16.

func OfBools(v []bool) Data
    OfBools is the values of a bool column.

func OfBytes(v [][]byte) Data
    OfBytes is the values of a binary or utf8 column, and of a uuid column,
    whose values are 16 bytes each.

func OfDecimals(v []Decimal) Data
    OfDecimals is the values of a decimal column: the unscaled values.

func OfList(offsets []int, elems Data) Data
    OfList is the values of a list, a fixed-size list or a map column. Row i is
    the elements offsets[i] to offsets[i+1] of elems, so offsets has one more
    value than there are rows and never decreases. For a fixed-size list the
    offsets are regular, 0, size, 2*size... For a map elems is OfStruct(keys,
    values).

func OfNulls(n int) Data
    OfNulls is a column of the null type: n rows, all null.

func OfStrings(v []string) Data
    OfStrings is the values of a utf8 or binary column.

func OfStruct(fields ...Data) Data
    OfStruct is the values of a struct column: one Data per field, of the same
    length.

func OfVariants(vals []any) Data
    OfVariants is the values of a Variant column, one of: nil (a null row),
    bool, any Go integer (an unsigned one up to the largest int64), float32,
    float64, string, []byte, time.Time (a timestamp, in microseconds,
    or in nanoseconds when it has a finer part), VariantDecimal, []any and
    map[string]any of these, up to 128 levels deep. Another Go type is an error
    of Write that names the type and the row.

func (d Data) Nulls(null []bool) Data
    Nulls returns the Data with these rows marked null: null[i] is true when row
    i is null. It has as many values as the Data has rows. A column that is not
    nullable takes none.

type Decimal struct {
	// Has unexported fields.
}
    Decimal is the unscaled value of a decimal of any precision, on 256 bits
    in two's complement: 32 bytes, no pointer. The scale is in the Type of the
    column, not in each value: Text takes it. The representation is unique,
    so == and Cmp agree on equality; Cmp also orders.

func DecimalFromBig(v *big.Int) (Decimal, error)
    DecimalFromBig returns the decimal whose unscaled value is v. It returns an
    error when v does not fit in 256 bits, that is when it is outside -2^255 to
    2^255-1.

func DecimalFromInt64(v int64) Decimal
    DecimalFromInt64 returns the decimal whose unscaled value is v.

func (d Decimal) Big() *big.Int
    Big returns the value as a new big.Int.

func (d Decimal) Cmp(o Decimal) int
    Cmp compares the values: -1 when d is less than o, 0 when equal, +1 when
    greater.

func (d Decimal) Int64() (int64, bool)
    Int64 returns the value as an int64, and false when it does not fit.

func (d Decimal) Text(scale int) string
    Text prints the value with the point scale digits from the right: the
    sign when negative, the digits, no exponent. A negative scale adds zeros:
    the value is multiplied by 10^-scale.

type Expr struct {
	// Has unexported fields.
}
    Expr is a filter: a small tree of comparisons of columns with Go values,
    and of And, Or and Not. The zero Expr keeps every row. Build one with Col
    and the methods of Ref.

    A comparison with a null is unknown, like in SQL, and And, Or and Not are
    three-valued: a row is kept only when the filter is true for it. IsNull
    is never unknown. For the floats, NaN equals nothing (not even itself), is
    neither less nor greater than anything, and so is different from everything,
    like in Go.

    The literals are Go values: any integer or float type, bool, string (for a
    Utf8 column), []byte (Binary, UUID), Decimal, time.Time (date and timestamp)
    and time.Duration (time), compared exactly even when finer than the unit
    of the column (Eq never matches then). An integer can be compared with a
    float column. The filter is checked against the schema before any read:
    a literal that does not fit the column, and for Eq, Ne and In an integer out
    of the range of the column, are errors.

func And(e ...Expr) Expr
    And is true when every expression is. With none, it keeps every row.

func Not(e Expr) Expr
    Not is true when e is false, false when e is true and unknown when e is.

func Or(e ...Expr) Expr
    Or is true when one of the expressions is. With none, it keeps no row.

type Field struct {
	Name string
	Type Type
}
    Field is a named field of a struct.

type File struct {
	// Has unexported fields.
}
    File is an open Vortex file. It is safe for concurrent use.

func Open(r io.ReaderAt, size int64) (*File, error)
    Open reads the trailer, the footer and the schema of the Vortex file in r,
    which holds size bytes. It reads the last 64 KiB in one call, and one more
    range when the footer reaches further back. A file larger than 64 KiB costs
    one more read, for its first bytes. The caller keeps r open for as long as
    the File is used.

func OpenFile(path string) (*File, error)
    OpenFile opens the Vortex file at path. Close it when done.

func OpenMapped(path string) (*File, error)
    OpenMapped opens the Vortex file at path like OpenFile does, and maps
    it in memory: a scan reads the segments where they are, without a copy,
    so a scan that reads a part of the file (some columns, a range of rows,
    the rows a filter keeps) only touches that part. Close it when done.

    It is for a local file that nothing truncates while it is read. The
    operating system reports a mapped byte that it cannot read, a truncated file
    or a failing disk, by stopping the process, where OpenFile returns an error.
    The columns of a batch are views of the file: they are not read after Close,
    which gives the memory back once the scans still running have ended,
    each with an error that wraps os.ErrClosed.

    Where the platform cannot map a file, or refuses to map this one, OpenMapped
    is OpenFile.

func (f *File) Close() error
    Close closes the file that OpenFile opened: a scan still running returns
    an error that wraps os.ErrClosed. It does nothing for a File made by Open.
    A second call returns nil.

func (f *File) NumRows() int64
    NumRows returns the number of rows of the file.

func (f *File) Scan(ctx context.Context, q Query, columns ...string) iter.Seq2[*Batch, error]
    Scan reads the columns of the file that meet the query, batch by batch,
    in order, on the calling goroutine. A batch has at most 8,192 rows and is
    dense: its Len is the number of rows kept, and a batch without any is not
    returned. The batch has the columns that are named, in that order, and
    every column in the order of the schema when none is. A name is a top-level
    column; the fields of a struct come with Column.Field. A column that only
    the filter needs is read and not returned.

    An unknown column, an invalid range, or a filter that does not fit the
    schema is the error of the first iteration, before any read.

func (f *File) Schema() *Schema
    Schema returns the schema of the file.

type Query struct {
	// Filter is exact: a row is returned when it is true, and the caller never has to filter
	// again. The statistics of the file are used to skip what it rules out.
	Filter Expr
	// Rows limits the scan to a range of rows.
	Rows Range
}
    Query selects the rows of a scan: the rows of Rows for which Filter is true.
    The zero value selects every row.

type Range struct{ Start, End int64 }
    Range is a half-open range of rows of a file: Start is the first row,
    End the one after the last. The zero value is the whole file, so an End of 0
    means the end of the file. A range outside the file is clamped to it.

	// Has unexported fields.
}
    Ref is a column, or a field of a struct column, to compare.

func Col(path ...string) Ref

func (r Ref) Eq(v any) Expr
    Eq is true for the rows whose value equals v.

func (r Ref) Ge(v any) Expr
    Ge is true for the rows whose value is at least v.

func (r Ref) Gt(v any) Expr
    Gt is true for the rows whose value is greater than v.

func (r Ref) In(vs ...any) Expr
    In is true for the rows whose value equals one of vs.

func (r Ref) IsNull() Expr
    IsNull is true for the rows that are null, and false for the others.

func (r Ref) Le(v any) Expr
    Le is true for the rows whose value is at most v.

func (r Ref) Lt(v any) Expr
    Lt is true for the rows whose value is less than v.

func (r Ref) Ne(v any) Expr
    Ne is true for the rows whose non-null value differs from v.

type RowWriter[T any] struct {
	// Has unexported fields.
}
    RowWriter writes rows, values of the struct type T, to a Vortex file. It is
    the other half of Rows: the schema comes from the fields of T, with the same
    tags, and the Go types are the ones that Rows reads. It drives a Writer,
    which sets the chunks, the statistics and the encodings.

    A field is the column named by its tag, vortex:"name", else its own name.
    The tag vortex:"-" skips the field, unexported fields are skipped and
    embedded structs are flattened. The Vortex type of a field follows from its
    Go type:

      - bool, the numbers (int and uint are 64 bits), string (utf8), []byte
        (binary), [16]byte (uuid) and vortex.Decimal (a decimal, with the tag
        option decimal(p,s), for precision p and scale s, which int64 takes as
        well, p up to 18);
      - time.Time is a timestamp in microseconds, UTC, with no zone in the type;
        the options timestamp(unit) and timestamp(unit,zone) pick another unit
        (s, ms, us or ns) and a zone name, and date a date in days;
      - time.Duration is a time of day in nanoseconds; the option time(unit)
        picks another unit;
      - any is a Variant, nullable: nil is a null row, and the other values are
        the ones that OfVariants takes (see Column.Variant for what Rows gives
        back);
      - sql.Null[X] and *X are nullable, anything else is not;
      - a struct is a struct, []X a list, [N]X a fixed-size list and map[K]V a
        map, whose keys are not nullable and whose order of entries is the one
        of Go's iteration. The options of a list field apply to its elements.

    A T that cannot be written is the error of the first Write, and of Close if
    Write was never called: it names the field and its Go type.

    A Write call copies what it needs, so the caller can reuse the rows as soon
    as it returns. A field that is a number, a bool, a decimal, a time, a uuid,
    a string or a []byte, plain or in sql.Null, is read without allocating.
    Pointers, structs, slices and maps allocate.

    Write and Close are not safe for concurrent use.

func NewRowWriter[T any](w io.Writer, o WriteOptions) *RowWriter[T]
    NewRowWriter returns a RowWriter that writes to w. It does not close w.

func (w *RowWriter[T]) Close() error
    Close writes the footer. A second Close returns nil, and Close does not
    close the io.Writer.

func (w *RowWriter[T]) Write(rows []T) (int, error)
    Write adds rows to the file. It returns the number of rows it took, which is
    less than len(rows) when it returns an error. An error closes the writer for
    writing, and every later call returns it.

type WriteOptions struct {
	// Edition is the edition the file must be readable with, as the upstream names it
	// ("core 2025.05.0"). Empty is the newest the library knows, "core 2026.08.3". The writer
	// only makes what the edition has: a file for an edition before "core 2026.08.0" has the
	// older zone maps (vortex.stats) and only the legacy file statistics, one before
	// "core 2025.10.0" has no listview and no run-length or masked arrays, and so on. An
	// unknown edition, or a type it cannot hold (a uuid before "core 2026.08.3", a map before
	// "core 2026.08.2", a fixed-size list before "core 2025.10.0"), is an error of the first
	// Write or Close.
	Edition string
	// Buffer is the bytes of rows, as they are before compression, that may wait to be
	// compressed together: the writer compresses the chunks that wait on every core, and each
	// one holds its rows and the memory of its compressor until it is written. 0 is the
	// default, a queue of chunks whose length depends on the schema (two chunks of about 1 MiB
	// a column, 16 at least). A smaller Buffer lowers the memory of the writer and uses fewer
	// cores at once; under the size of a chunk, the chunks are compressed one at a time, on one
	// core. A larger one only matters for a file of few columns. The rows of the file do not
	// depend on it, the order of its segments may.
	Buffer      int
	Compression Compression
}
    WriteOptions are the options of a Writer.

type Writer struct {

}
    Writer writes a Vortex file. It needs an io.Writer and never seeks.

    A column takes the Data its type calls for: Of for the numbers (the Go type
    is the one of the column, int32 for Int32; the storage of a date, a time or
    a timestamp, and uint16 for the bits of a Float16), OfBools, OfStrings or
    OfBytes for Utf8 and Binary, OfBytes for a UUID, OfDecimals, OfVariants for
    a Variant, OfNulls, OfStruct, and OfList for a list, a fixed-size list and a
    map. Each Write adds rows. The rows of a column are cut into chunks that do
    not depend on how the caller splits them: at multiples of 8,192 rows, about
    1 MiB of data a chunk. Each column carries the statistics a reader uses to
    skip a zone, and a column of few distinct values is written as a dictionary.
    Write copies the rows into a buffer of a few MiB a column, so they reach the
    io.Writer when a chunk is full, and at Close.

    Write and Close are not safe for concurrent use.

func NewWriter(w io.Writer, s *Schema, o WriteOptions) *Writer
    NewWriter returns a Writer of a file with this schema. Nothing is written
    until the first Write or Close. A schema that cannot be written (a decimal
    of precision 0, say) is reported by the first Write or Close.

func (w *Writer) Close() error
    Close writes the footer. The writer is closed for writing, and w is left
    open. A file with no row has one empty chunk. A second Close returns nil;
    Close returns the error that closed the writer for writing, if any.

func (w *Writer) Write(cols ...Data) error
    Write adds rows to the file: one Data per field of the schema, all of
    the same length. It returns an error when a Data does not fit its field,
    and then, or when the io.Writer fails, the writer is closed for writing.
    Write reads the slices of the Data and does not keep them. The rows are in
    the io.Writer when Close returns, some of them before.
