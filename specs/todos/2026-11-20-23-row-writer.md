# `RowWriter[T]` writes a slice of Go structs to a Vortex file

## Problem

The column writer exists after the previous specs. Goal 1 of `docs/goals.md` asks for the
other half of the row API: "writing a slice of structs to a file takes a few lines and no
configuration", familiar to parquet-go users (`Write([]T) (int, error)`, `Close()`).

## Proposal

1. In `rowwriter.go`:
   ```go
   func NewRowWriter[T any](w io.Writer, o WriteOptions) *RowWriter[T]
   func (w *RowWriter[T]) Write(rows []T) (int, error)
   func (w *RowWriter[T]) Close() error
   ```
   It builds a `*Schema` from `T` and drives a `Writer`.
2. **Schema from `T`**, the mirror of the plan of `Rows[T]`. Reuse that code: one function
   that maps a struct type to fields, tags and kinds, used by both sides.
   - Go type to Vortex type: the table of `docs/interface.md`, read right to left. `int`
     and `uint` are 64 bits. `string` is Utf8, `[]byte` is Binary, `[16]byte` is UUID,
     `time.Time` is a timestamp in microseconds UTC, `time.Duration` is a time in
     nanoseconds, `vortex.Decimal` needs its precision and scale in the tag.
   - `sql.Null[X]` and `*X` are nullable, anything else is not.
   - tags: `vortex:"name"`, `vortex:"-"`, and the options `decimal(p,s)`, `date`,
     `timestamp(ms)`, `timestamp(us,Europe/Paris)`, `time(us)` to pick another logical type
     for the same Go type.
   - nested: struct, `[]X` (list), `[N]X` (fixed-size list), `map[K]V`.
   - a `T` that cannot be written is the error of the first `Write`, and of `Close` if
     `Write` was never called. It names the field and its Go type.
3. **The fill** goes from rows to reused column buffers, with the same `internal/unsafex`
   reads as the reader's writes, for the same kinds. A `Write` call copies what it needs:
   the caller may reuse `rows` as soon as `Write` returns.
4. `Write` returns the number of rows taken. On error it is the count written before the
   error, and the writer is then closed for writing: later calls return the same error.
5. `Close` flushes and writes the footer. A second `Close` returns nil. `Close` does not
   close `w`.
6. `Example` functions: write rows, write rows then read them back. Update `api.txt`.

## Tests

- Round trip in Go, seeded: for a struct covering every kind of step 2, write then read
  with `Rows[T]`: equal. With empty input, one row, a batch larger than a chunk, all nulls.
- Tag options: each one gives the expected `Schema` (compare with a schema built by hand).
- The reference reads it: the rows are written to the folder of `make interop` with their
  canonical hashes, like the column writer's files.
- Errors, with their text: `T` is not a struct, a `chan` field, a `map` with a key type
  that Vortex cannot hold, `vortex.Decimal` without `decimal(p,s)`, a bad tag option.
- An `io.Writer` that fails at call N, for every N: `Write` or `Close` returns the error,
  and every later call returns it too.
- `testing.AllocsPerRun`: 0 allocation per `Write` call on a struct of fixed-width fields
  and `[]byte`, once the writer runs.
- The unsafe read against a `reflect` read, for every field kind.

## Resolved open questions

- The default logical type of `time.Time` is a timestamp in microseconds, UTC, no zone in the type; a tag option covers the rest. (autopilot: recommended answer)

## Open questions

- **The default logical type of `time.Time`.** Recommended answer: a timestamp in
  microseconds, UTC, no zone in the type. It is what Parquet and Arrow tools expect, and a
  tag option covers the rest.
