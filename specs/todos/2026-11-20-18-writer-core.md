# `NewWriter` writes a valid Vortex file with plain encodings, and the reference reader opens it

## Problem

There is no writer. This spec writes the simplest file the reference reader accepts: every
logical type, canonical arrays only, no compression. It also sets up the gate that judges
every later writer spec: the Rust implementation reads our files and gets back the values
we wrote (`docs/goals.md` goal 2, `docs/testing.md` section 4).

Upstream paths are in `~/code/other/vortex`. The write order of a file is in
`vortex-file/src/footer/serializer.rs:119-203`.

## Proposal

1. **Wire writers.** `internal/flatbuf` gains a builder (tables, vectors, strings, structs,
   unions, written back to front, "minimal" finish: no size prefix, no identifier).
   `internal/protowire` gains an encoder. `internal/scalar` gains the `ScalarValue`
   encoder.
2. **Schema constructors**, in `schema.go`: `NewSchema(fields ...Field) *Schema`,
   `Field{Name, Type}`, and one constructor per kind: `Int8`...`Float64`, `Bool`, `Utf8`,
   `Binary`, `Null`, `DecimalOf(precision, scale)`, `ListOf(elem)`, `FixedSizeListOf(elem,
   n)`, `MapOf(key, value)`, `StructOf(fields...)`, `Date(unit)`, `Time(unit)`,
   `Timestamp(unit, zone)`, `UUID`, and `Type.AsNullable()`.
3. **The API** of `docs/interface.md`, in `writer.go` and `data.go`:
   ```go
   func NewWriter(w io.Writer, s *Schema, o WriteOptions) *Writer
   func (w *Writer) Write(cols ...Data) error
   func (w *Writer) Close() error
   func Of[T Number](v []T) Data // also OfBools, OfStrings, OfBytes, OfDecimals
   func OfStruct(fields ...Data) Data
   func OfList(offsets []int, elems Data) Data
   func (d Data) Nulls(null []bool) Data
   type WriteOptions struct{ Compression Compression } // Default, Compact, None
   ```
   - `Write` takes one `Data` per top-level field, all of the same length. `Data` gives the
     physical shape and the schema the logical type: `Of[int64]` for a timestamp,
     `OfBytes` (16 bytes each) for a UUID, `OfList(offsets, OfStruct(keys, values))` for a
     map, `OfList` with regular offsets for a fixed-size list;
   - a mismatch (count, length, shape against type, a null in a non-nullable field) is
     the error of that `Write`, naming the field. After an error the writer is closed for
     writing;
   - `Write` copies nothing it can write straight away, and keeps no reference to the
     caller's slices after it returns;
   - `Close` writes the footer. It does not close `w`. A second `Close` returns nil.
   - in this spec the three `Compression` values behave like `None`.
4. **The file**: `VTXF`, then per `Write` call one flat segment per leaf column (buffers
   with their padding, the `Array` flatbuffer, its `u32` length:
   `vortex-array/src/serde.rs:56-160`), then the dtype, the layout tree (`vortex.struct`
   over `vortex.chunked` over `vortex.flat`, a single chunk unwrapped), the footer (array
   ids, layout ids, segment map sorted by offset), the postscript and the 8-byte trailer.
   Arrays: `vortex.primitive`, `vortex.bool`, `vortex.null`, `vortex.varbinview`,
   `vortex.listview` or `vortex.list`, `vortex.fixed_size_list`, `vortex.struct`,
   `vortex.decimal`, `vortex.ext`, `vortex.map`. Segment alignment as upstream
   (`vortex-file/src/segments/writer.rs:65-89`).
5. **Memory**: column buffers are owned by the writer and reused between `Write` calls.
   Only an `io.Writer` is needed: offsets are counted, never sought.
6. **The interop gate.** `tools/oracle/oracle.py check <dir>`: for each `<name>.vortex`
   with a `<name>.hashes.json` in the folder, open it with the reference reader, compute
   the canonical hashes, compare. `interop_test.go` (build tag `interop`) writes the
   files and their hashes into a temp folder. `make interop` runs it, then the oracle,
   against the pinned `vortex-data` and against the latest release. It is added to CI
   (`.github/workflows/build.yml`, Go 1.27 leg, with `uv`). `docs/testing.md` section 9:
   "Reference reads our files" becomes "in place".
7. **Edition conformance**: a test asserts that every identifier in a file we wrote is in
   `internal/edition`.

## Tests

- Round trip in Go, seeded, for every logical type, nullable and not, alone and nested:
  write, read with `Scan`, compare. Hard cases: 0 row, 1 row, all null, NaN and `-0`,
  integer limits, empty and 1 MB strings, 5 levels of nesting, 3 `Write` calls of
  different sizes, 200 columns.
- `make interop` green on the same data.
- Errors, with their text, for each mismatch of step 3.
- An `io.Writer` that fails at call N, for every N: `Write` or `Close` returns the error.
- `testing.AllocsPerRun`: 0 allocation per `Write` on fixed-width columns once running.
- `internal/flatbuf`: what the builder writes, the reader reads, for every kind of field.
