# The two heavy encodings are decoded: Zstd and Pco

## Problem

Files written in compact mode use `vortex.zstd` for strings and binary and `vortex.pco`
for numbers (`vortex-btrblocks/src/builder.rs:46-97` upstream). Both are in the edition
since `core 2025.06`. The 3 `*.compact.vortex` dataset files and `default_compact` cannot
be read without them.

Zstd is the one place where a dependency is allowed: `github.com/klauspost/compress`
(Florent, 2026-11-19, `docs/goals.md`). Pco has no Go implementation we may import, so its
decoder is written here.

Upstream paths are in `~/code/other/vortex/encodings/`.

## Proposal

1. **Zstd.** Add `github.com/klauspost/compress` to `go.mod`. `make deps` already allows
   it and `make nocgo` must stay green: use the pure Go decoder, no cgo build tag.
   `vortex.zstd` (`zstd/src/array/`, decode at `array/mod.rs:226` and `decompressor.rs`):
   - metadata `{dictionary_size, frames: [{uncompressed_size, n_values}]}`
     (`zstd/src/lib.rs:79-114`);
   - buffers: the dictionary when `dictionary_size` is above 0, then one buffer per frame.
     Child 0 is the validity;
   - numbers: a frame decompresses to the raw little-endian values of its valid rows;
   - strings and binary: each value is a `u32` LE length followed by its bytes
     (`array/mod.rs:552-556`);
   - only valid rows are stored: nulls are put back from the validity;
   - one decoder is kept per scan and reused. `uncompressed_size` is checked against a
     limit before allocating, and the decompressed size must equal it.
2. **Pco** (`pco/src/`, decode at `array/mod.rs:199`): `vortex.pco` wraps the `pco` crate,
   version 1.1.0 (`Cargo.toml:217` upstream).
   - metadata `{header: bytes, chunks: [{pages: [{n_values}]}]}` (`pco/src/lib.rs:37-68`);
   - buffers: one chunk metadata buffer per chunk, then the pages. Child 0 the validity;
   - write `internal/pco`, a decoder for Pco's wrapped format (the one without the
     standalone file framing): header, chunk metadata (mode, delta encoding, bins per
     latent variable), pages (ANS state, tANS-coded bin indexes, offset bits). Every mode
     and delta encoding that format version 1.1.0 defines: at least the classic, integer
     multiplier, float multiplier and float quantization modes, and no delta, consecutive
     delta of any order and lookback delta. Types: the 8 integer types, `f32`, `f64`, and
     `f16` if the format has it;
   - the decoder checks every count and bit length against its input. A truncated page is
     `ErrCorrupt`.
3. Entries leave `pending`: `zstd`, `pco`, `default_compact`.

## Tests

- The harness: `zstd`, `pco` and `default_compact` pass.
- Zstd: frames made in the test with the klauspost encoder, for numbers and strings, with
  and without a dictionary, with nulls. A frame that decompresses to the wrong size, a
  string length past the frame, a missing dictionary buffer: `ErrCorrupt`.
- Pco: test vectors produced by the reference, committed in `testdata/vectors/pco/`. A
  short Python script in `tools/oracle` writes one single-column file per case (each
  mode, each delta kind, each type, constant data, 1 value, 0 value, more than one page)
  with its values. `internal/pco` decodes the buffers of each and compares.
- Pco, damage: every vector truncated at 20 offsets returns an error, no panic.
- `make nocgo` and `make deps` pass with the new module.
